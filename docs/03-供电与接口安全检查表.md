## 答辩必答题（背下来）

**问：为什么舵机不能从板载电源取电？**

答：三个原因：
1. **电流不够**：SG90 堵转电流约 700mA，四个同时启动瞬间可达 2~3A，
   而板载 LDO 与 USB 口总共只能给几百 mA，会直接把 3.3V 拉垮，MCU 复位；
2. **干扰**：舵机是 brushed DC 电机 + 电位器，换向时产生大量尖峰噪声，
   会通过电源耦合到 MCU 与 MPU6050 的模拟部分，表现为 ADC 跳变、I2C 误码；
3. **共地反灌**：如果舵机从板载 5V 取电，大电流回路会经过板子的地平面，
   在地平面上产生压降，PWM 参考电平跟着抖，舵机自己也会抖。

**问：随机指向原理图上的 VBUS / 5V / 3V3 / NRST / BOOT0，说明来源、去向与风险。**

- VBUS：来自 USB 座 J1 的 5V，去向是 LDO 输入 + 板载 5V 排针；风险是热插拔浪涌、与外部 5V 对冲；
- 5V：LDO 输入与排针；风险是外接大电流负载导致压降；
- 3V3：LDO 输出，供 MCU/传感器/LED；风险是过流、短路；
- NRST：复位网络，10k 上拉 + 100nF 到地；风险是长线引入干扰导致误复位，必要时并 100nF；
- BOOT0：启动模式选择，10k 下拉到地（从 Flash 启动）；风险是误拉高进入 System Memory，表现为"程序不跑"。
