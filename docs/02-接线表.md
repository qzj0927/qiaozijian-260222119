# 02 接线表（STM32F401CCU6）

> 这张表要贴进设计说明，答辩时评审会对照它看原理图。

## 1 主控引脚分配

| 功能 | 引脚 | 外设/模式 | 备注 |
|---|---|---|---|
| 底座舵机 | PB4 | TIM3_CH1 AF2 | 脉宽 500~2500µs |
| 肩舵机 | PB5 | TIM3_CH2 AF2 | 同上 |
| 肘舵机 | PB0 | TIM3_CH3 AF2 | 同上 |
| 夹爪舵机 | PB1 | TIM3_CH4 AF2 | 同上 |
| 调试串口 TX | PA9 | USART1_TX AF7 | 115200 8N1 |
| 调试串口 RX | PA10 | USART1_RX AF7 | 只收不用 |
| MPU6050 SCL | PB8 | I2C1_SCL AF4 | 400kHz |
| MPU6050 SDA | PB9 | I2C1_SDA AF4 | 400kHz |
| USB DM | PA11 | USB_OTG_FS | 全速设备 |
| USB DP | PA12 | USB_OTG_FS | 全速设备 |
| LED | PC13 | GPIO 输出 | 板载，低电平点亮 |
| 按键 | PB12 | GPIO 输入上拉 | 外接按键到 GND |
| SWD | PA13/PA14 | SWDIO/SWCLK | 下载调试 |
| 1ms 时基 | — | TIM2 | 内部，不占引脚 |

**为什么不用 TIM1(PA8~PA11)**：TIM1_CH4 在 PA11 上，与 USB DM 冲突。
用 TIM3 的 PB4/PB5/PB0/PB1 四路，引脚连续、好插排线，且避开 USB 与串口。

## 2 供电接线（这一节最容易烧板子）

```
                    ┌──────────────────┐
   5V 2A 适配器 ────┤ +5V  ──┬── 舵机1 红线
                    │        ├── 舵机2 红线
                    │        ├── 舵机3 红线
                    │        └── 舵机4 红线
                    │
                    ├ GND ───┬── 舵机1~4 棕线
                    │        ├── 主控板 GND   ← 共地点，只有这一处
                    │        └── USB-TTL GND
                    └──────────────────┘

   MPU6050: VCC -> 板载 3.3V, GND -> 板载 GND, SCL -> PB8, SDA -> PB9, AD0 -> GND
```

| 规则 | 原因 |
|---|---|
| 舵机红线**只接** 5V 电源，不接板子 5V | 4 个 SG90 同时启动电流可达 2~3A，会把板载 LDO 拉垮导致复位 |
| 舵机棕线与板子 GND **必须共地** | PWM 是电平信号，没有公共参考就乱动 |
| 5V 电源入口并 **1000µF 电解 + 0.1µF 瓷片** | 吸收舵机启动瞬间的电流冲击 |
| 上电顺序：先 GND → 再舵机 5V → 最后主控 USB | 避免反灌 |
| 断电顺序相反 | 同上 |
| 调试时 ST-Link 的 3.3V **不要**与板载 3.3V 同时接 | 两个电源对冲，容易烧 LDO |

## 3 上电/断电顺序图

```
上电：  接好 GND  ──►  舵机 5V 上电  ──►  主控上电(USB/ST-Link)  ──►  等自检打印
断电：  主控断电  ──►  舵机 5V 断电  ──►  最后拆 GND
```

测量点建议（答辩会问"测量点在哪"）：
- **VBUS**：USB 座 5V 脚（万用表对 GND）；
- **板载 3V3**：任一 3.3V 排针；
- **舵机 5V**：舵机排针红线处，示波器看启动瞬间跌落到多少（低于 4.5V 就要加大电容/换电源）。

## 4 各组件的线序（SG90）

| 颜色 | 含义 |
|---|---|
| 棕 / 黑 | GND |
| 红 | VCC 4.8~6V |
| 橙 / 黄 / 白 | PWM 信号 |

> 不同批次 SG90 线序可能不同，**接之前用万用表量一下**：
> 红线与外壳之间是电机，棕线与红线之间约 3~5kΩ。
